# Demo Script (5-7 minutes)

Open `outputs/nasa_procurement_dashboard_presentation.html` directly in a
browser before you start -- no server, no network needed.

## 1. Framing (30s)

"This is a NASA procurement intelligence dashboard built from real
USAspending.gov contract transaction data, FY2020 through today. It's an
unofficial, educational project -- that disclosure is in the header, along
with when the data was last refreshed and how it was processed."

Point at the header: data period, transaction count, **processing mode**
(`DETERMINISTIC_FALLBACK` / `CACHED_AGENT` / `LIVE_AGENT`), source.

## 2. Executive Overview (60-90s)

- KPI row: net obligations, gross positive obligations, deobligations,
  transaction count, unique awards, unique normalized suppliers.
- Point out the **partial fiscal year warning** if the current FY is showing
  (explain: FY-to-date totals aren't directly comparable to a completed year).
- Annual obligation trend chart -- gross (blue) vs. deobligations (red) vs.
  net (line).
- Category composition -- NASA spend across the two-level taxonomy.
- **Key Findings** panel -- explain these are generated by the Procurement
  Insights Agent, but every finding cites the exact metric behind it and
  uses cautious language ("potential opportunity," "warrants review") --
  never a fraud or compliance claim.

## 3. Year-over-Year Trends (60s)

- FY selector + comparable-year-to-date toggle -- demonstrate switching
  between full-year and YTD comparison to show why that distinction matters
  for a partial current year.
- Supplier concentration trend (HHI + top-5 share) -- explain HHI briefly.
- Category trend lines across fiscal years.

## 4. Transaction Explorer (60-90s)

- Point out the disclosure line: how many of the total transactions are
  embedded in this file vs. the full processed dataset on disk.
- Filter live: pick a fiscal year, then a category, then set a minimum
  confidence or amount.
- Sort by clicking a column header (e.g. Signed Amount).
- Find a **DEOBLIGATION** row -- show the signed negative amount is intact,
  not zeroed or dropped.
- Click **Export filtered CSV** -- show the download.

## 5. Supplier Analysis (45-60s)

- Pick a supplier with multiple raw name variants.
- Show the consolidated variants chip row and the resolution
  confidence/evidence line (e.g. "Grouped by shared UEI...").
- Point out category mix pie chart and NASA awarding offices.

## 6. Categories & Opportunities (45-60s)

- Pick a category with a high HHI / tail-spend share.
- Show leading suppliers table and the low-confidence review queue --
  explain this is exactly how a reviewer would triage what the deterministic
  and agent layers were *not* confident about, rather than hiding it.

## 7. Wrap-up (30s)

"Everything in this file is self-contained -- open it with no internet
connection and it works identically. A local refresh command
(`python -m src.cli refresh`) re-pulls from USAspending, re-runs the full
pipeline, and regenerates this exact file; `python -m src.cli build`
rebuilds it from the last processed dataset with zero network calls, which
is what guarantees this demo works even if USAspending or the internet is
down."

## If something breaks live

- Internet down / USAspending down: the presentation file already open in
  the browser is unaffected -- it's fully self-contained.
- Asked to show a live refresh: run `python -m src.cli build` instead of
  `refresh` -- rebuilds instantly from cached processed data, no network.
